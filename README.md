# Crossfire Field

A small, original browser tank duel inspired by Atari's *Combat*. Maneuver around barricades, line up shots, and score more hits than your opponent in a 2 minute, 16 second match. Choose ricocheting or straight shells, and play against the computer or a friend on the same device.

[Play online](https://intrepion.github.io/kata-inspired-by-combat-codex-dot/)

## Controls

- Player 1: W/S to drive forward/reverse, A/D to turn, Space to fire.
- Player 2: arrow keys to drive and turn, Enter to fire.
- Touch: hold the on-screen controls. Choose **Local player** to reveal the second set.

Use Pause to stop the clock. Changing opponent resets the match. Each tank can have up to two shells on the field; a hit scores one point and briefly protects the target.

## Run locally

Open `index.html` in a modern browser; there are no build steps or dependencies. Fonts fall back to system fonts when offline.
